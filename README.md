## 🌟 About The Project

**Smart Calculator** is an all-in-one web calculator designed to make everyday calculations simple, fast, and interactive.

It includes basic and scientific calculations along with calculation history, memory functions, unit conversion, stopwatch, countdown timer, keyboard support, and dark/light mode.

---

## ✨ Features

### 🧮 Basic Calculator
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🟰 Instant calculations
- ⌫ Backspace
- 🔄 Clear button
- `( )` Brackets

### 🔬 Scientific Calculator
- 📐 Sin
- 📐 Cos
- 📐 Tan
- √ Square Root
- x² Square
- xʸ Power
- log Logarithm
- ln Natural Logarithm
- ! Factorial
- π Pi
- e Euler's Number
- 1/x Reciprocal
- DEG / RAD mode

### 💾 Memory Functions
- **MC** — Memory Clear
- **MR** — Memory Recall
- **M+** — Add to Memory
- **M−** — Subtract from Memory
- **MS** — Store in Memory

### 📜 Calculation History
- Automatically saves calculations
- View previous calculations
- Stores results using LocalStorage
- Clear history whenever needed

### 🌙 Dark & ☀️ Light Mode
- Dark mode
- Light mode
- Theme preference is saved
- Modern purple and navy design

### ⏱️ Stopwatch
- ▶️ Start
- ⏸️ Pause
- 🔄 Reset
- Real-time timer

### ⏳ Countdown Timer
- Set minutes and seconds
- ▶️ Start
- ⏸️ Pause
- 🔄 Reset
- Automatic completion

### 🔄 Unit Converter

Supports:

- 📏 Length
- ⚖️ Weight
- 🌡️ Temperature
- ⏰ Time
- 💾 Data

### ⌨️ Keyboard Support

Use your keyboard for faster calculations.

- `Enter` → Calculate
- `Backspace` → Delete
- `Escape` → Clear

### 🕐 Live Date & Time

The application displays the current date and time and updates automatically.
